# 🚀 Advanced Disk Scheduling Simulator

An interactive desktop application built using **Python**, **Tkinter**, and **Matplotlib** to simulate and visualize popular disk scheduling algorithms used in operating systems.

This tool helps users understand disk head movement and compare how different algorithms affect system performance.

---

## 📌 Project Overview

Disk scheduling plays a vital role in optimizing system performance within an operating system.  
This simulator provides a graphical representation of disk head movements, making complex concepts easier to understand through visualization.

Users can input disk requests, select an algorithm, and instantly view the execution order along with key performance metrics.

---

## ✨ Features

✅ Interactive graphical user interface  
✅ Real-time disk head movement visualization  

### Supported Algorithms:
- **FCFS (First Come First Serve)**
- **SSTF (Shortest Seek Time First)**
- **SCAN (Elevator Algorithm)**
- **C-SCAN (Circular SCAN)**

### Performance Metrics:
- Total Seek Time  
- Average Seek Time  
- Throughput  
- Service Order  

✅ Input validation and error handling  
✅ Clean and modular code structure
